Google Sheet Se Form Kaise Link Karein?

Jab koi user website par form bharega, to uska data aapki Google Sheet me auto-save ho jayega. Niche diye 5 simple steps ko follow karein:

1
Google Sheet Banayein

Apne Google Account se sheets.google.com kholein aur ek New Sheet banayein (Naam: Swastik Hospital Appointments).

2
Extensions > Apps Script Kholein

Google Sheet ke Top Menu me Extensions par click karein aur Apps Script par click karein.

3
Ye Script Code Paste Karein

Purana code mita kar niche diya hua code paste kar dein:

function doPost(e) {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    var data = JSON.parse(e.postData.contents);
    
    // Auto-create Header Row if Sheet is Empty
    if (sheet.getLastRow() === 0) {
      sheet.appendRow(["Timestamp", "Name", "Phone", "Email", "Date", "Service", "Message"]);
    }
    
    sheet.appendRow([
      data.Timestamp || new Date().toLocaleString(),
      data.Name || "",
      data.Phone || "",
      data.Email || "",
      data.Date || "",
      data.Service || "",
      data.Message || ""
    ]);
    
    return ContentService.createTextOutput(JSON.stringify({result: "success"}))
      .setMimeType(ContentService.MimeType.JSON);
  } catch(error) {
    return ContentService.createTextOutput(JSON.stringify({result: "error", error: error.message}))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
4
Deploy As Web App

Top Right me Deploy > New Deployment par click karein.

• Select type: Web App

• Description: Hospital Form API

• Who has access: Anyone (Ye step jaruri hai)

• Deploy button par click karein aur Google Permission Allow karein.

5
URL Ko config/site-data.js Me Save Karein

Deploy hone ke baad aapko ek Web App URL milega (jo https://script.google.com/macros/s/.../exec se shuru hoga).

Us URL ko copy karein aur apne website folder me config/site-data.js file khol kar googleSheetScriptUrl me paste kar dein!
